# Historical scripts

These files are retained only for auditability. They belong to the earlier point-level workflow and are not part of the revised experiment.

Known methodological problems in the historical workflow include pseudo-replication of assay intervals, global-mean labels assigned to unassayed rows, target-derived predictors, and validation steps that do not consistently preserve drillhole or spatial separation.

Use `run_analysis.py` and `src/mmex_validation.py` for the corrected analysis.
